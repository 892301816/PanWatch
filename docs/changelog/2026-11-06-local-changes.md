## 本次理财工作台调整

实施日期：2026-11-05 至 2026-11-06。提交标题：`feat(portfolio): 重整理财工作台并保留持仓与关注操作`。完整提交号见指定记录目录内的 `Git提交历史.txt` 最新一条；本文件随本次代码一起提交。

### 页面结构

- 应用导航使用“理财”，区域名称为“理财工作台”；主视图收敛为“持仓、关注、计划”，默认进入持仓。
- 取消与持仓重复的工作台总览、常驻 AI 右栏，以及目标、流水、账户设置的同级导航。
- 保留原 `/portfolio` 入口，兼容旧视图保存值，并通过视图参数支持页面切换与返回。
- 持仓采用全宽列表；资产摘要收为总资产、今日盈亏、持仓浮动盈亏、可用资金四项。统计账户切换时，摘要、持仓和计划检查使用相同范围。
- 待处理事项按需出现：到期定投可直达原成交确认表单；止损/止盈计划检查展示触发原因；行情缺失不视为没有风险。

### 持仓与关注兼容

- 保留账户折叠、排序、持仓新增/编辑/删除、成本与数量、多市场行情和人民币折算。
- 提供精简列与完整列切换；精简模式保留标的、现价、市值、盈亏、今日盈亏、持有计划和操作。
- “详情、加仓、减仓”直接显示于桌面与手机持仓行；加减仓同级可见，继续复用原有费用、成本、现金变更和交易记账表单。
- K 线、相关新闻、深度分析、Agent 配置/运行、风控、编辑/删除等通过具名“更多”菜单进入。
- 关注页保留市场、分组、预警、搜索、排序和研究操作；不展示持仓资产摘要或记账控件，也不把关注标的计入资产。

### 计划与上下文操作

- 账本、账户管理及全账户组合分析按需在侧栏打开。账户流水继承当前账户范围，也可在侧栏更改范围。
- 计划页保留新建定投、确认成交、删除功能，增加进行中/已暂停筛选和暂停/恢复；暂停计划仍可找到。
- 定投按启用状态和下次计划日期排列；到期待办能传递账户与计划 ID，打开原成交表单。
- 理财目标收为辅助摘要及编辑弹窗，不虚构应急金达成率、被动收入进度或真实净值曲线。
- 账户策略、费用、分红再投归账户设置；分红历史归统一账本。分红处理继续调用原全账户接口，界面明确提示范围。
- 组合 AI 分析明确覆盖全部账户，按需生成，不伪装成单账户或实时分析。

### 交互修复

- “更多”菜单原使用 `bg-popover`、`text-popover-foreground`，但 Tailwind 未注册对应颜色，导致背景透明、底层文字透出。本次补齐主题映射，明暗主题均生成不透明背景与文字样式。
- 新增紧凑摘要、金额隐私显示、移动布局及有文字的操作菜单。隐私功能用于旁观/截图遮蔽；部分原值仍在 DOM 中，不是数据访问控制。用户主动打开的编辑表单仍显示可编辑值。
- 侧栏关闭后回到记录入口或当前视图；弹窗继续使用现有 Dialog 组件。
