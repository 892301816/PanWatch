================================================================================
 TideView Pine Script 引擎 — 函数与变量知识库
 用途: 提供给 AI 大模型，生成可在 TideView 引擎中运行的 Pine Script 代码
================================================================================

【重要说明】
本引擎实现了 Pine Script v5 的绝大部分语法和常用函数库。
生成代码时只能使用本文档中列出的函数和变量，禁止臆造或使用本文档之外的函数。
回测与撮合按观潮本地 TradingView 口径引擎执行；不要在脚本或说明里建议用户切换回测模式。
主要限制:
  - 不支持 TradingView 云端 / 社区 CDN 库（import username/Library/版本）
  - request.dividends / earnings / economic / seed / currency_rate / quandl 为占位（返回 na）
  - 动态（非常量字面量）的 symbol / timeframe 无法静态预取，跨品种时可能得到 na

【给外部 AI 的硬性约定 — 写出可在观潮完美运行的脚本】
1. 第一行 //@version=5；指标用 indicator(...)，策略用 strategy(...)。
2. 只使用本文档与文末「动态函数白名单」中的 API；不要照搬 TradingView 独有社区库。
3. 周期、symbol 尽量写字面量（如 "D"、"60"、"000001.SZ"），避免 timeframe.period 拼出来的动态串做跨品种。
4. 策略里 request.security 默认用 barmerge.lookahead_off，禁止无必要的 lookahead_on；lookahead_on 配合 [1] 取前一已完成周期是无偏写法（TV 官方）。
5. 跨品种用 "代码.市场" 或 "市场:代码"（如 "000001.SZ"、"SZ:000001"）；同品种跨周期优先 syminfo.tickerid。
6. 需要库时优先 import MathUtils / SignalUtils，或 import 用户已保存在观潮里的脚本标题；不要写 TV CDN 路径。
7. A 股红涨绿跌；需要 T+1/整手数时在脚本内自行实现，不要假设引擎自动拦截。

================================================================================
第一部分：基本语法规则
================================================================================

1. 第一行必须是 //@version=5
2. 策略脚本必须声明:
   strategy("策略名", overlay=true, initial_capital=100000,
     commission_type=strategy.commission.percent, commission_value=0.1,
     default_qty_type=strategy.percent_of_equity, default_qty_value=10,
     pyramiding=1)
   ⚠ pyramiding 语义：
     本引擎 pyramiding=N 表示同方向最多 N 次入场（含同 ID 加仓）；
     pyramiding=1（默认）= 同方向最多 1 笔；pyramiding=2 = 首仓 + 1 次加仓；
     pyramiding=0 视为 1（仅允许首仓、禁止加仓）。
3. 指标脚本必须声明:
   indicator("指标名", overlay=true/false)
4. 支持的语法结构:
   - 变量赋值: x = 1, var float x = na (var 声明持久变量), varip float x = na
   - 条件语句: if/else if/else
   - switch 语句: switch value / case1 => ..., 也支持 x = switch ...（表达式赋值）
   - 循环: for i = 0 to n, for i = 0 to n by step, while condition
   - 三元表达式: condition ? value1 : value2
   - 历史引用: close[1], high[3]（方括号索引访问前 N 根 K 线的值）
   - 函数定义: myFunc(param1, param2) => expression（支持多行函数体）
   - method 方法: method myMethod(MyType self, ...) => expression
   - 用户自定义类型 (UDT): type MyType / field1 = default_value
   - enum 枚举: enum MyEnum / value1 / value2
   - 解构赋值: [a, b] = ta.macd(close, 12, 26, 9)
   - 具名参数: plot(series=close, title="收盘价", color=color.red)
   - import: 支持内置库 MathUtils / SignalUtils，以及用户已保存在观潮中的脚本（按标题或 id）
     示例: import MathUtils as mu
     不支持: TradingView 云端路径（如 import TradingView/Foo/1 as foo）
5. 编写约定:
   - A 股场景遵循红涨绿跌配色：上涨/买入信号用红色，下跌/卖出信号用绿色。
   - 回测语义与 TradingView 一致；如需 T+1/整手数等市场规则，在脚本内自行实现
   - 注释使用中文
   - 所有参数用 input 函数定义，方便用户调整

第六部分：策略函数（strategy.*）

【策略交易指令】
strategy.entry(id, direction, qty, limit, stop, oca_name, oca_type, comment, alert_message, disable_alert)
  id: 交易标识（字符串）, direction: strategy.long 或 strategy.short
  qty: 数量（可选）, limit: 限价, stop: 止损价

strategy.close(id, immediately)
  id: 入场标识；空字符串或省略时平掉全部仓位
  immediately: 是否在当前 tick 立即成交（默认 false，下一 bar 开盘）
  ⚠ 本引擎不支持 comment/qty/qty_percent/alert_message/disable_alert，传入会被静默忽略
strategy.close_all(immediately)
  immediately: 是否在当前 tick 立即成交（默认 false）

strategy.exit(id, from_entry, qty, qty_percent, profit, loss, limit, stop,
    profit_pct, loss_pct, trail_points, trail_price, trail_offset)
  id: 出场标识符
  from_entry: 绑定的入场 id（默认等于 id）
  qty / qty_percent: 平仓数量（绝对值或百分比 0-100）
  profit / loss: 止盈 / 止损 tick 数（价差 = tick 数 × 最小变动价位；要按价位止盈止损请用 limit / stop（绝对价位））
  limit / stop: 止盈价格 / 止损价格（绝对价位）
  profit_pct / loss_pct: 相对入场价的百分比止盈/止损

--- request.security / request.security_lower_tf ---

request.security(symbol, timeframe, expression, gaps, lookahead)
  同品种或多品种、跨周期数据请求。观潮会预取外品种 K 线并对齐主图时间窗。
  周期字面量建议: "1"/"3"/"5"/"15"/"30"/"60"/"120"/"240"/"D"/"W"/"M"（及 1D/1W/1M）
  symbol 写法:
    - 同品种: syminfo.tickerid（推荐）或 syminfo.ticker
    - 跨品种: "000001.SZ"、"600000.SH"、"SZ:000001"（字面量；失败返回 na，不会静默换成当前品种）

request.security_lower_tf(symbol, timeframe, expression, ignore_invalid_symbol)
  目标周期低于主图时使用（返回数组系列）。同样支持跨品种字面量。

【expression 支持范围（字符串 / 嵌套 ta.* / 元组）】
价格与合成: close, open, high, low, volume, time, hl2, hlc3, ohlc4, hlcc4, bar_index
均线与波动: ta.sma/ema/rma/wma/hma, ta.highest/lowest, ta.stdev, ta.atr, ta.linreg
动量: ta.rsi, ta.cci, ta.mfi, ta.mom, ta.roc, ta.change, ta.vwap
交叉: ta.crossover, ta.crossunder
元组: ta.macd → [macd, signal, hist]；ta.bb / ta.bbands → [basis, upper, lower]
数学: math.abs / floor / ceil / round 及常见二元运算、比较
可嵌套，例如: ta.sma(ta.rsi(close, 14), 5)
不在白名单内的复杂函数体 / 用户自定义函数 → 运行时报「暂不支持的表达式」

【推荐写法示例】
// 同品种高周期
htfClose = request.security(syminfo.tickerid, "D", close)
htfRsi = request.security(syminfo.tickerid, "W", ta.rsi(close, 14))
[macdLine, signalLine, histLine] = request.security(syminfo.tickerid, "D", ta.macd(close, 12, 26, 9))

// 跨品种（字面量）
refClose = request.security("000001.SZ", "D", close)
refEma = request.security("SH:600000", "60", ta.ema(close, 20))

// 低周期（主图为日线时取 60 分钟序列）

【边界与降级】
- 动态 symbol / timeframe（非常量）→ 可能无法预取 → na 或空

================================================================================
第九点五部分：缠论函数（chanlun.*）
================================================================================

这些函数读取当前图表同口径的缠论识别结果，用于把缠论信号接入 Pine 策略。
它们不接受参数，均按当前 bar 返回结果；信号识别本身存在确认延迟，确认时刻晚于
结构位置，脚本里可叠加价格/均线/量能等条件做二次确认。

【重要】信号触发 bar 与图表标注位置为何不同：
chanlun.bp*Buy / bp*Sell / divergence* 在「结构首次被确认」的那根 bar 上才返回
true（因果回放，绝不使用未来 K 线）；而图表上的缠论指标会把转折点标记画在
结构位置（可能早于确认时刻若干根 K）。这不是 bug：脚本回测必须按确认时刻
取值才不引入未来函数；图表标注的是结构归属位置，方便人工复盘。若需要与
图表视觉对齐做研究，可用 signal.explain 里的 confirmTime / 结构 index 自行对拍。

转折点:
chanlun.bp1Buy(), chanlun.bp1Sell()       第 1 类向上转折 / 向下转折，返回 bool
chanlun.bp2Buy(), chanlun.bp2Sell()       第 2 类向上转折 / 向下转折，返回 bool
chanlun.bp3Buy(), chanlun.bp3Sell()       第 3 类向上转折 / 向下转折，返回 bool
chanlun.bpAnyBuy(), chanlun.bpAnySell()   任一类向上转折 / 任一类向下转折，返回 bool

背驰与中枢:
chanlun.divergenceBottom(), chanlun.divergenceTop()  底背驰 / 顶背驰，返回 bool
chanlun.zsUpper(), chanlun.zsLower()      最近中枢上沿 / 下沿；无中枢返回 na
chanlun.zsBreakUp(), chanlun.zsBreakDown() 当前 bar 突破中枢上沿 / 下沿，返回 bool

笔与信号强度:
chanlun.biDirection()                     当前所在笔方向：1 上行，-1 下行，0 未知
chanlun.signalStrength()                  当前 bar 最新缠论信号强度；无信号返回 0

[macdLine, signalLine, hist] = ta.macd(close, 12, 26, 9)
rsiVal = ta.rsi(close, 14)
longCond = ta.crossover(macdLine, signalLine) and hist > 0 and su.inRange(rsiVal, 40, 70)
exitCond = ta.crossunder(macdLine, signalLine)

if longCond
    strategy.entry("做多", strategy.long)

    strategy.close("做多")

第十四部分：与 TideView 内置指标联动（重要）
================================================================================

TideView 内置了大量原生技术指标，由引擎 IndicatorEngine 统一计算并以专业级视觉渲染。
完整列表见本文档末尾「动态内置指标清单」段（运行时自动从注册表生成，永远是当前版本最新值）。

Pine Script 的 ta.* 函数（ta.sma/ta.ema/ta.macd/ta.rsi/ta.bb/ta.atr/ta.cci/
ta.stoch/ta.dmi/ta.adx/ta.sar/ta.supertrend/ta.hma/ta.willr 等）在**数值上
已对齐内置 calculators**，可以放心调用，无需担心口径差异。

【联动规则一：Companion 自动加载（基础策略映射）】
当用户激活内置 strategy 模板时，系统会根据 COMPANION_INDICATOR_MAP 自动把
配套的内置指标添加到画布（如画布已有则幂等跳过）。完整映射表：

  基础单指标策略：
    pine-ma-crossover-strategy        → 无（脚本自画快慢双 EMA，周期可调）
    pine-macd-strategy                → MACD
    pine-rsi-strategy                 → RSI
    pine-stochastic-strategy          → 无（STOCH 内置指标已下架，脚本自画 %K/%D）
    pine-kdj-strategy                 → KDJ
    pine-cci-strategy                 → CCI
    pine-wr-strategy                  → WILLR
    pine-roc-strategy                 → ROC
    pine-sar-strategy                 → SAR
    pine-supertrend-strategy          → SUPERTREND
    pine-bias-strategy                → BIAS
    pine-trix-strategy                → TRIX
    pine-obv-strategy                 → OBV
    pine-emv-strategy                 → EMV
    pine-psy-strategy                 → PSY

配套内置指标按其自身参数（默认或画布已有）显示，与本策略参数不同时以策略参数为准。

【联动规则二：脚本绘图规范（关键）】
为避免 companion 与脚本自绘副图重复（双副图），生成策略代码时请遵循：

1. overlay=true 主图策略：
   - 不要用 plotshape / label 画买卖信号：回测引擎会按实际成交（下一根开盘）
     在主图统一标 B/S 并跟随主题涨跌色，脚本自画会与之重复且早一根
   - 不要自己 plot MACD/RSI/KDJ 等常见副图指标（让 companion 自动负责）
   - 主图可以 plot 趋势线、均线、通道（供人眼参考）
   - 示例：
     //@version=5
     strategy("示例", overlay=true)
     [macdLine, sigLine, hist] = ta.macd(close, 12, 26, 9)
     longCond = ta.crossover(macdLine, sigLine)
     if longCond
       strategy.entry("做多", strategy.long)
     // 买卖点由回测 B/S 统一标注，不再 plotshape

2. overlay=false 副图策略：
   - **默认不要**自己 plot RSI/KDJ/SLOWKD/CCI/MACD/BOLL/WILLR/ROC/BIAS/TRIX/OBV/EOM/
     STOCHRSI/MFI/DMI/ADX/ATR/AROON/VORTEX/FISHER/TSI/KST/CONNORSRSI/
     SCHAFF/WAVETREND/CHOPPINESS/PSY/ULTOSC/CMO/MOM/SQUEEZE/CVD/BBW/BBP/ZSCORE/
     COPPOCK/SMIERGODIC/SMI/PMO/BOP/ELDERFORCE/VOLOSC/PVT/AD/CMF/CHAIKIN/ASI/
     STDDEV/HISTVOL/MASSINDEX/HURST/ULCER/CORR/BETA/RS 等 300+ **有原生指标**
     的副图曲线（companion 机制会自动负责），否则画布会出现两个重复的副图面板。
   - 系统已有 300+ 原生副图指标（均有专业级渲染，以文末动态清单为准），
     极少需要脚本自画副图。
   - bgcolor 用来标记信号区域是合理的，不属于重复绘图。
   - overlay=false 时 bgcolor / plotshape 需加 force_overlay=true 才画到主图（否则落到脚本自己的副图，会生成空副图）。
   - 买卖点同样由回测 B/S 统一标注，不要再 plotshape。

3. 指标脚本的信号可视化通过 plotshape 完成（location.belowbar / location.abovebar），
   不要用条件表达式 color + plot 模拟箭头；策略脚本的买卖点交给回测 B/S。

【联动规则三：数值一致性保证】
以下 ta.* 函数已通过单测验证，与内置 calculators 数值完全一致：
  ta.sma, ta.ema, ta.rsi, ta.macd, ta.atr, ta.bb, ta.stdev

写代码时可以放心使用这些函数，**无需自己手算**：
  ❌ 错误示范：自己用 for 循环算 SMA
  ✅ 正确写法：ma = ta.sma(close, length)

【联动规则四：查看画布指标的手段】
用户可以在 UI 侧边栏的"指标"面板添加/删除任意内置指标，或通过
command palette 快速搜索指标名。生成的代码不需要、也不应该
"手动触发 UI 添加指标"——这由用户交互完成。

- 不要使用 array.new<float>() 泛型语法，改用 array.new_float()
