# 2026-11-25 策略工作台与回测面板重构

状态：前端工作区改动完成，本地 Docker 已重建为最新代码；本次提交到 Git，云端服务器按挂载源码方式 `git pull + docker restart` 更新。

## 操作变化

### K 线工作台

- 脚本工具条（脚本编辑 / 开始回测 / 收藏 / 我的策略 / 回测结果 / 下载函数知识库）从底部移到顶栏下方，桌面端顺序固定为「顶栏 → 工具条 → 读数行 → 图例 → 主图 → 副图 → 状态栏」。
- 「策略」「布局」两个无效下拉菜单删除，只保留真正可用的入口。
- 指标入口从侧边栏抽屉改为**锚定浮层**：浮层贴在「指标」按钮下方，内部分两步——指标列表（搜索 + 已添加 chips + 21 个指标）与参数配置（`←` 标题、带标签的参数行、周期下拉、显示位置分段按钮、取消/添加到图表）。指标数从 6 个扩展到 21 个（主图 MA/EMA/WMA/BOLL/ENV/BBI，副图 VOL/VMA/MACD/RSI/KDJ/WR/CCI/ATR/OBV/BIAS/ROC/MTM/DMA/TRIX/PSY/DMI），参数校验与默认值随指标声明生成。
- 十字光标 OHLC 提示框改为**跟随鼠标**，靠近画布边缘自动内收，不再固定贴右上角。

### 尺寸与滚动

- 桌面端只保留**一层滚动**：工作台固定为一屏，内容向下生长；放大 K 线或回测区时把下方内容推下去，超出可视区才出现唯一滚动条。此前页面 / 工作台 / 图表区三层各带滚动，出现两根滑轨。
- K 线区底部、每条副图顶部各有独立拖拽条，均**不设高度上限**；副图高度写入 `localStorage`，双击恢复自动比例（主图与各副图按 2:1:1 分享）。

### 回测结果与我的策略

- 常驻底部回测面板改为**弹窗**，从顶栏下方展开，带 4 张 KPI 卡（策略收益 / 最大回撤 / 胜率 / 交易笔数）与分段式 tab；空状态、收益曲线、信号与订单沿用原渲染。
- 「我的策略」弹窗与页面共用同一份 JSX：搜索、比较、编辑规则、开始回测、复制、删除、应用范围、回收站全部在弹窗内可用；弹窗顶部补齐「检查一笔买卖」「创建策略」两个入口，编辑时提供 `表单 ｜ 脚本编辑` 两个 tab。
- 回测统计卡改为缺字段即不渲染，不再出现「— 元」；最大回撤以百分比为主值，金额仅在 Pine 口径（存在 `initial_capital`）时作为副行。
- 表单优化：三个条件折叠区显示条数；「什么时候买入/退出/不买」改为三张并排卡片；模板参数改为两列网格，布尔用勾选、数字带 `−/+` 步进；风险与执行改为三列并带单位。
- 模板信号的条件文案不再显示「所选模板入场信号 = 是」，改用模板真实信号描述。
- 历史验证的标的不再需要手动输入：默认**跟随工作台当前 K 线**，并可下拉选择持仓 / 关注列表，只有选「其他代码，手动输入」才出现输入框。

### Pine 主线

- 工作台内置模板改为 Pine 策略脚本（双均线 / 指数均线 / 反向交叉），旧四语句草稿在加载时自动迁移到 Pine 模板，不再产出缺字段的老报告。
- 「编辑规则」进入表单（主路径），需要写 Pine 时从弹窗切到「脚本编辑」，跳转工作台并自动打开脚本编辑器（`autoEdit`）。
- 编辑器补齐观潮式状态：脏标记（已修改，未保存）、行数、错误数；行号槽按错误行标红；关闭编辑器时若有未保存修改会二次确认。

### 移动端

- 手机端隐藏页面标题区与图例行，压缩顶栏与读数行，副图默认高度 64px，主图获得更多空间；脚本 / 回测 / 结果三个全屏视图与底部导航保持不变。
